보안 이벤트 → 마케팅 액션 : Action + Property 기반 자동화

앞장 이벤트 택소노미를 속성(Property) 단위로 심화 — 이벤트가 '무엇'이 아니라 '어떤 상태'인지로 마케팅이 갈린다. 보안은 막고구현, 마케팅은 되돌린다설계. 제안된 속성 대부분이 이미 실제 컬럼으로 존재.
